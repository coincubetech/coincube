## Standing decisions that apply to all new artboards
- Shell: Launcher-world screens (sign-in, create, import/restore, opening) use the V3-Launcher-Spin top bar and tokens; in-Cube screens use the V2 shell with the single-Cube top bar (Lock confirmation inline), icon sidebar, state-word chips, eye toggle. Reference assets only by those URLs.
- Wording (item 6): use **network** everywhere in the Launcher and the app; the filter chip "Chain ▾" becomes "Network ▾"; "chain family" in the Key card becomes "network family"; never "chain" in UI copy except inside the product names "Bitcoin Blake2b" or "cross-chain" (Spark's own kind label) and "on-chain".
- Copy: distill rules (each idea once; consequences in labels or confirmation steps; one muted prototype footer; one-or-two-word stepper labels). Safety wording quoted from source stays verbatim.
- Every artboard: levers theme, reducedMotion, hideBalances (where amounts exist) plus its own state levers; real controls; themed focus ring; drawn 1.5px icons; no emoji; no cards except where the incumbent uses them (wallet containers on Overview, one bounded form region per flow step).
- File naming: `V6-<Area>-<Screen>.dc.html`, 1440×900 unless a flow needs more height (then 1440×1100). Do not edit any existing file unless the brief names it.
