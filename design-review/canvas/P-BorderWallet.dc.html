Border Wallet

What is a Border Wallet?

A Border Wallet key is derived from a visual pattern you select on a word grid. The key is never stored — it exists only while you are using it.

To create one, you will:

  1. Generate or enter a 12-word recovery phrase (the Entropy Grid seed)
  2. Select 11 cells from the word grid (your Pattern)
  3. Memorize the checksum word (the final derived word)
  4. Review and confirm the derived key

Important: To reconstruct this key you need all three components: the recovery phrase, the exact pattern, and the checksum word. Write them down and store them securely.
