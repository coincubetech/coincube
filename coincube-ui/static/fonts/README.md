The Tenshu redesign uses IBM Plex Sans 400/500/600 for UI text and IBM Plex
Mono 400/500 for addresses, transaction IDs and detailed amounts. The new
`IBMPlexSans-SemiBold.ttf`, `IBMPlexMono-Regular.ttf`, and
`IBMPlexMono-Medium.ttf` files are unmodified IBM Plex fonts from
[`IBM/plex`](https://github.com/IBM/plex), under the SIL Open Font License 1.1
in `OFL.txt` and `IBMPlexMono-OFL.txt`.
